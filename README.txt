СЕМЕЙНЫЙ БЮДЖЕТ — как установить

Это веб-приложение: его нужно один раз выложить на любой бесплатный хостинг
статических сайтов, после чего оно ставится на телефон как обычное приложение
и дальше работает без интернета.

Ваши данные на хостинг НЕ попадают. Хостинг отдаёт только «пустое» приложение,
а все записи хранятся в памяти каждого телефона. Если кто-то откроет ту же
ссылку, он увидит чистое приложение без ваших данных.


1. ВЫЛОЖИТЬ ПРИЛОЖЕНИЕ (один раз, с компьютера)

Вариант: GitHub Pages (бесплатно)
  1) Зарегистрируйтесь на github.com.
  2) Нажмите «New repository», придумайте название (например, budget),
     оставьте Public и создайте.
  3) Нажмите «uploading an existing file» и перетащите ВСЕ файлы из этой папки
     (index.html, sw.js, manifest.webmanifest, три картинки .png). Нажмите «Commit changes».
  4) Откройте Settings → Pages. В «Branch» выберите main и / (root), нажмите Save.
  5) Через 1–2 минуты там появится адрес вида https://ВАШЕ-ИМЯ.github.io/budget/

Подойдёт и любой другой хостинг статических сайтов (Netlify, Cloudflare Pages и т.п.) —
главное, чтобы адрес начинался с https://


2. УСТАНОВИТЬ НА ТЕЛЕФОНЫ

  iPhone: откройте адрес в Safari → кнопка «Поделиться» → «На экран Домой».
  Android: откройте адрес в Chrome → меню ⋮ → «Установить приложение»
           (или «Добавить на главный экран»).

После первого открытия приложение работает и без интернета.


3. НАСТРОИТЬ НА ДВОИХ

  Телефон 1: «Начать» → имена и остатки → «Ещё → Обмен данными» → «Создать семейный ключ».
  Телефон 2: «У супруга(и) уже есть приложение» → ввести ключ с первого телефона.
  Телефон 1: «Отправить» → выбрать чат с супругом(ой) в мессенджере.
  Телефон 2: сохранить файл → «Открыть файл».

Дальше обменивайтесь так же, когда удобно: раз в день или раз в неделю.
Ключ лучше переписать вручную, сидя рядом, и не пересылать в тот же чат, что и файлы.


4. ВАЖНО

  • Раз в месяц сохраняйте резервную копию: «Ещё → Настройки → Резервная копия».
  • Если удалить приложение с экрана или очистить данные браузера, записи на этом
    телефоне пропадут. Их можно вернуть из файла со второго телефона или из копии.
  • Потеряли ключ — создайте новый («Обмен данными → Сменить ключ») и введите его
    на обоих телефонах.
